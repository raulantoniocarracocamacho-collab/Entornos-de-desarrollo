# Evaluación Práctica - Unidad 1: Introducción a los Lenguajes de Marcas

## 📌 Descripción de la Tarea
Esta práctica evalúa los conocimientos fundamentales sobre los **Lenguajes de Marcas** adquiridos durante la Unidad 1 del módulo. El objetivo principal es comprender la estructura, sintaxis, validación y correcta utilización de etiquetas en documentos marcados, estableciendo las bases para el desarrollo web y la estructuración de datos.

---

## 🎯 Objetivos de Aprendizaje
* Comprender el concepto, evolución e importancia de los lenguajes de marcas (HTML, XML, JSON, etc.).
* Analizar la estructura básica y jerárquica de un documento bien formado.
* Reconocer y aplicar correctamente las etiquetas principales, atributos y tipos de datos.
* Validar la sintaxis y detectar errores según los estándares actuales (W3C).

## 🛠️ Requisitos Técnicos y Herramientas
* **Editor de código:** Visual Studio Code (o similar).
* **Navegador Web:** Google Chrome, Firefox o Edge para visualización.
* **Validadores:** Validador oficial del W3C ([validator.w3c.org](https://validator.w3c.org/)).

## 📑 Criterios de Evaluación
* **Sintaxis y Estructura (40%):** Correcto anidamiento de etiquetas, apertura y cierre adecuado, uso correcto de minúsculas/mayúsculas.
* **Cumplimiento de Especificaciones (30%):** Inclusión de todos los elementos obligatorios indicados en el enunciado de la tarea.
* **Validación (20%):** Código libre de errores y advertencias críticas según los estándares W3C.
* **Documentación y Presentación (10%):** Claridad en el archivo `README.md`, comentarios adecuados en el código y orden en las carpetas.
